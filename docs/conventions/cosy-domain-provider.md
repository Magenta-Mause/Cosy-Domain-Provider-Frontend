# Cosy Domain Provider

Free subdomain provider service for cosy-hosting.net — users claim subdomains and point them at their Cosy instance.

- **Live:** https://domain-provider.cosy-hosting.net (staging: https://staging.domain-provider.cosy-hosting.net)
- **Repos:** github.com/Magenta-Mause/Cosy-Domain-Provider (backend / frontend / deployment)
- **Local:** clone the repo(s) listed above into `~/projects/cosy-domain-provider/` — single-repo → directly into `~/projects/cosy-domain-provider/`, multi-repo → one subfolder per repo (`~/projects/cosy-domain-provider/<repo-name>/`). Always `git pull` before reading. See [repo conventions](README.md#local-repos--clone-on-demand-pull-before-reading).
- **Cluster:** namespaces `cosy-prod` and `cosy-staging` (each runs backend + frontend + postgres)

## Idea
Users claim subdomains (e.g. `castle.play.cosy-hosting.net`) and point them at the IP of their self-hosted Cosy instance. The backend provisions the corresponding AWS Route53 A records. A paid **Cosy+** tier (billed via Stripe) unlocks custom labels, CNAME records, and higher quotas.

## Stack
- **Frontend:** React 19 SPA, TypeScript, Vite, Bun. Redux Toolkit, TanStack Router, TanStack Query, axios, zod, Tailwind CSS, shadcn/ui (Radix + CVA), lucide-react. Full EN/DE i18n (react-i18next). Cloudflare Turnstile (`@marsidev/react-turnstile`), qrcode.react + input-otp for TOTP 2FA. Biome + Vitest + Testing Library + Lighthouse CI.
- **Backend:** Spring Boot 4.0.5 / Java 21 REST API. Spring Web MVC, Spring Security, Spring Data JPA. JWT auth (jjwt), bucket4j rate limiting, Micrometer + Prometheus, springdoc OpenAPI. AWS SDK v2 Route53, Stripe (stripe-java). PostgreSQL. Schema managed by Hibernate `ddl-auto: update` (no Flyway).
- **Infra / Deploy:** Docker, nginx, Kubernetes, Kustomize, ArgoCD.

## Notes for agents
- **i18n:** single typed resources file at `src/i18n/resources.ts` (inline `enCommon`/`deCommon` objects exported `as const` for typed keys). Add strings there, not in per-feature JSON.
- **API client is generated by orval** — config `orval.config.ts`, output `src/api/generated/domain-provider-api.ts` (+ `model/`), custom axios mutator `src/api/axios-instance.ts`. Regenerate with `bun run gen:api` (curls `/api/v3/api-docs` then runs orval). Do not hand-edit generated files.
- **Data bootstrapping** goes through the `useDataLoading` hook (`src/hooks/useDataLoading/useDataLoading.ts`) — wires generated API calls into Redux slices (auth, subdomains, settings).
- **Auth guards** use TanStack Router `beforeLoad` — `requireFullAuth` at `src/lib/require-full-auth.ts`, applied in `dashboard.tsx`, `settings.tsx`, `billing.tsx`, `admin/index.tsx`, etc.
- Backend Route53 code: `services/aws/Route53Service.java`; Stripe: `services/billing/StripeService.java` + `StripeWebhookController`.
- No react-hook-form and no Playwright despite what you might assume — forms use zod directly and E2E/quality tooling is Vitest + Lighthouse CI.
